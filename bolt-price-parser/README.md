# Bolt Price Parser

Веб-приложение, которое показывает **актуальную стоимость поездки Bolt по всем тарифам**
для заданных адресов начала и конца. Данные берутся в реальном времени из веб‑портала
**Bolt Business / Ride Booker** (`business.bolt.eu`) — единственной доступной по логину/паролю
поверхности Bolt, где видны цены по категориям.

> Город по умолчанию — **Рига (Rīga)**. Меняется в `.env`.

---

## ⚠️ Важно прочитать

- **У Bolt нет публичного API** для расчёта стоимости поездки. Инструмент автоматизирует
  веб‑портал через headless‑браузер (Playwright). Это **противоречит условиям использования
  Bolt** и может привести к капче, запросу 2FA или блокировке аккаунта. Используйте на свой
  риск и только со своим аккаунтом.
- **Секреты не хранятся в коде.** Логин/пароль задаются только в `.env` (в `.gitignore`).
  Если вы где‑то присылали пароль в открытом виде — **смените его**.
- Вёрстка портала может меняться — тогда нужно поправить селекторы/логику в
  `src/boltBusiness.js`. Для диагностики есть режим `DEBUG_CAPTURE=1` (скриншот + дамп JSON).

---

## Как это работает

1. `npm run login` — один раз вручную входите в Bolt Business (email/пароль + код из
   письма/СМС). Сессия сохраняется в `.session/storageState.json`.
2. Сервер (`npm start`) поднимает веб‑интерфейс. При каждом запросе он:
   - открывает портал с сохранённой сессией (повторный логин не нужен);
   - вводит адреса «откуда/куда» через автоподсказки;
   - перехватывает JSON‑ответы бэкенда Bolt и/или читает DOM;
   - извлекает список тарифов: название, цена, время подачи, множитель спроса (surge).

Извлечение цен устойчивое: сначала парсятся сетевые JSON‑ответы
(`src/priceExtractor.js`), при неудаче — фолбэк на чтение DOM.

## Установка

Требуется Node.js 18+.

```bash
cd bolt-price-parser
npm install            # поставит зависимости и браузер Chromium для Playwright
cp .env.example .env   # заполните BOLT_EMAIL и BOLT_PASSWORD
```

Если `postinstall` не скачал браузер, выполните вручную:

```bash
npx playwright install chromium
# на Linux при нехватке системных библиотек:
npx playwright install-deps chromium
```

## Первый вход (сохранение сессии)

Выполняется один раз (и повторно, когда сессия протухнет):

```bash
HEADLESS=false npm run login
```

Откроется окно браузера — войдите в аккаунт и, если попросят, введите код подтверждения.
После успешного входа сессия сохранится автоматически.

> На сервере без графики (headless‑окружение) вход в headed‑режиме невозможен. В этом случае
> выполните `npm run login` на своём компьютере и скопируйте файл
> `.session/storageState.json` на сервер.

## Запуск

```bash
npm start
```

Откройте <http://localhost:4000>, введите адреса и нажмите «Узнать цены».

## API

- `GET /api/health` — статус (заданы ли доступы, есть ли сессия).
- `POST /api/prices` — тело `{ "pickup": "...", "destination": "..." }`.
  Ответ:

```json
{
  "pickup": "Rīga, Brīvības iela 1",
  "destination": "Rīga, Lidosta «Rīga»",
  "city": "Rīga",
  "currency": "€",
  "fetchedAt": "2026-08-09T17:00:00.000Z",
  "tariffs": [
    { "name": "Bolt", "price": "€12.50", "eta": "3 min", "surge": 1 },
    { "name": "XL", "price": "€18.90", "eta": "5 min", "surge": 1.2 }
  ],
  "source": "bolt-business-web"
}
```

## Настройки (.env)

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `BOLT_EMAIL`, `BOLT_PASSWORD` | доступы Bolt Business | — |
| `BOLT_BASE_URL` | адрес портала | `https://business.bolt.eu` |
| `BOLT_DEFAULT_CITY` / `BOLT_DEFAULT_COUNTRY` | город/страна | `Rīga` / `Latvia` |
| `HEADLESS` | фоновый браузер | `true` |
| `GEO_LAT`, `GEO_LNG` | координаты по умолчанию | центр Риги |
| `PORT` | порт сервера | `4000` |
| `DEBUG_CAPTURE` | сохранять скриншот+JSON при запросе | `0` |

## Отладка

Если тарифы не находятся:

1. Установите `DEBUG_CAPTURE=1` в `.env` и повторите запрос.
2. Посмотрите скриншот и `*.json` в папке `.debug/` — там видно, что реально пришло со страницы.
3. При изменившейся вёрстке скорректируйте подсказки/селекторы в `src/boltBusiness.js`
   (`PICKUP_HINTS`, `DEST_HINTS`) или ключи в `src/priceExtractor.js`.

## Альтернатива: внутренний мобильный API

Более стабильно (и с явным `surge_multiplier`) цены отдаёт внутренний API
мобильного приложения (`user.live.boltsvc.net`), но он требует **токена**, который
можно получить только перехватом трафика приложения (MITM/HTTP Canary) и который не
привязан к email/паролю. Если сможете добыть такой токен — этот путь надёжнее; текущая
реализация использует доступный вам вход по логину/паролю.
